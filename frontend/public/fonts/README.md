# Self-hosted fonts

Poppins and DM Sans are the exact families observed in the user-pinned Petpooja reference. Downloaded from Google Fonts on 5 September 2026. The original OFL licenses are included beside the binaries. DM Sans is the complete variable font (including the rupee symbol); Poppins files are the Latin WOFF2 subsets. Served locally using next/font/local.
