# House studio demo

Mode: Operate. Extend the pinned navy/red world and self-hosted Poppins/DM Sans. The user authorized a quick, simple integration of the tested standalone house experiment on a separate application branch. Use the proven canvas-first layout and the application's generated shadcn Button. CSS stays below the house-app wrapper so returning to the workspace preserves its appearance.

The six-room synthetic house, measured room and adjoining rooms support Plan, Overview and Inside; selection precedes changes. Lights, furniture, one wall face and floor finishes are editable. Examples expose a selected JSON patch and explicit Apply. Session undo/redo and PNG/JSON download are included. Region controls and semantic selection support touch and keyboard; focused Plan dimensions remain readable at320px.

The existing private project/room/proposal flow remains available through Back to workspace. The home launches the demo in a dedicated tab so unsaved proposal inputs stay in place.

Lighting is illustrative and unshadowed, with no wall occlusion or calibrated photometry. Keep this disclosure next to the lighting environment controls. Retain independent Plan and editing recovery when graphics fail.
