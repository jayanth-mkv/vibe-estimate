# The shared saved home

Mode: Operate. A homeowner or designer chooses a complete authored floor, describes a desired change, and inspects the resulting validated home. The same owner project can become a shared designer/client room with one configured assistant, an actual conversation, precise design decisions and immutable draft agreement records.

The dominant canvas sits between a narrow room rail and one task panel. Plan, Overview and Inside are ordinary view controls. Design, Edit, Options and Share/Together replace each other in the panel. At narrow widths the room rail gives way to the Design area selector, the canvas remains full width, and tools stack below it. Generated shadcn controls retain keyboard behavior. The original brand, navy/red tokens and local fonts remain authoritative.

Selection precedes model edits; a selected shared-wall face persists across panels. Whole-home/room scope is explicit, object and surface lists are semantic, and numerical Plan regions provide non-drag selection. Furniture addition offers actual admitted models at valid candidate positions. Position, supported sizing and light settings are progressive controls. No arbitrary asset URL or generated code is executed.

The focal moment is a visible saved design changing: actual lighting, scaled furniture, and a precise surface that leaves its neighbours intact. Named saved versions compare at the same camera; factual change lists come from scene data. New views make no model call. Server-confirmed saves, staged-save recovery, explicit bounded retries and preserved conflicts remain distinguishable. Unknown outcomes preserve requests and cannot silently dispatch a paid retry.

The shared room uses the existing independent designer/client authentication and invitation flow. Both see the same home and messages. Send message does not impersonate either person; Ask assistant explicitly invokes the model. Client acceptance and designer approval each name an exact revision. Any later design needs fresh decisions. Draft agreements remain in a shared readable/downloadable library; design review is not a legal signature or authorization to start work. Private proposal prices remain private.

Actual lighting is illustrative and does not simulate wall occlusion. Authored dimensions and assumed ceilings need confirmation against the real home. Missing graphics preserves the independent Plan and editing controls. Native renderer screenshots, mesh/material checks, all-six-flow headed videos, keyboard/non-drag touch, accessibility, failures and separate identities establish release evidence; this brief is a design contract, not a passing result.
